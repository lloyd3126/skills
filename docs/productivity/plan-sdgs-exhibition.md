# SDGs 數位展覽規劃

## 用途

[plan-sdgs-exhibition](../../skills/productivity/plan-sdgs-exhibition/SKILL.md) 陪你將 SDGs 議題想法逐步發展成策展企劃。透過 RED 提問、案例比較、素材評估、敘事與原型規劃，整理有依據且能繼續製作的成果。

每次只完成當下需要的 MVP，依本輪目標、回合預算與完成條件收束。成果可以小到一個核心問題、一個展區草圖或一項試看任務，逐次累積成完整企劃。

## 適用時機

- 還沒想好主題，希望從生活或學習觀察找到 SDGs 策展方向。
- 已有想法或企劃，希望只補強觀眾定位、證據、敘事或互動等其中一部分。
- 需要整理原型製作規格，或規劃如何試看、取得回饋與修正。

## 安裝與開始使用

在 Codex 貼上以下提示；初步想法由 Agent 詢問，不需要先填完企劃：

```text
請將以下 skill 安裝到目前專案根目錄的 .agents/skills，讀取後直接開始引導我：
https://github.com/lloyd3126/skills/tree/main/skills/productivity/plan-sdgs-exhibition

先問我的初步想法，最多 3 回合釐清核心問題、目標觀眾與預期改變。達到 MVP 或用完預算就收束，留下成果、缺口與下次入口。
```

需要目前專案的位置，才能確定專案級安裝目的地。安裝後也可以直接描述需求，例如：

- 「陪我規劃 SDGs 展覽，今天只找方向，先聊三回合。」
- 「接續上次的舊衣展，這次只整理一個展區草圖，缺的資料先標待確認。」

已有觀察、素材、企劃或時間限制時可以提供；資訊不足時，Agent 會聚焦詢問或先提出標示假設的草案。

## 重要限制

回合預算是上限，已有可用成果時可以提前完成；用完預算仍有缺口時，先交付待補足成果。下次入口不要求當下繼續回答。

資料與 SDGs 目標對應仍需查證。無法存取來源時先標待查，不能把構想、Agent 評析或待安排的試看寫成已發生的事實或回饋。

本 skill 交付規劃與原型規格；實際網站、3D 場景或影音製作及對外發布，需要另外指定工作範圍。Plugin 安裝尚未驗證，以上提示是指定單一 skill 目錄的專案級安裝方式。

## 成功條件

每輪得到符合約定的最小成果，或明確知道目前缺什麼；Agent 達到停點時主動收束。已決定事項、待驗證內容與下次入口清楚，能在後續會談接著使用。

逐步整合後，企劃能對應核心問題、SDGs 目標、觀眾、主張與證據，並說清楚展覽敘事、原型範圍及可觀察的試看判準。企劃完成與原型、觀眾測試完成會分開標示。
